# Freight entry-state substitution

**Current state: fixed protocol; source and numerical execution pending.**

Freight planners need to distinguish concentration in estimated flow from verified spare transport capacity. This study will compare conditional recovery under a fixed set of hypothetical entry-state closures using FAF6.0 2022 water-import-to-truck estimates. It will retain every planned case and exact flow/cut certificates. No disruption, physical route, operational capacity or savings has been established. The next step is source reconciliation, then development checks and a dependency freeze before held summaries.

Read [the executable protocol](PROTOCOL.md), [constants](protocol.json) and [sources and rights](SOURCES.md). Independent research program; not peer reviewed. Separate formal-publication work remains private.
